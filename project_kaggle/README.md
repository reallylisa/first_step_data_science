### Описание проекта   
Проект посвящен решению задачи предсказания рейтинга отелей в рамках соревнования на платформе Kaggle. Работа производится над датасетом, в котором содержатся сведения о 515 000 отзывов на отели Европы.
 

Данный репозиторий содержит Jupyter Notebook с полным пайплайном обработки данных и обучением модели.  
 
#### Цель проекта  
Цель проекта — построить модель, которая должна предсказывать рейтинг отеля по данным сайта Booking на основе имеющихся в датасете данных.

### Какой кейс решает?  
Представьте, что вы работаете дата-сайентистом в компании Booking. Одна из проблем компании — это нечестные отели, которые накручивают себе рейтинг. Одним из способов обнаружения таких отелей является построение модели, которая предсказывает рейтинг отеля. Если предсказания модели сильно отличаются от фактического результата, то, возможно, отель ведёт себя нечестно, и его стоит проверить. Задача состоит в построении такой модели.  

**Метрика качества**  
В качестве основной метрики для оценки точности предсказаний используется MAPE (Mean Absolute Percentage Error) — средняя абсолютная процентная ошибка.

**Что практикуем**  
В проекте отрабатываются ключевые навыки специалиста Data Science:
- Работа с большими CSV-файлами и Pandas.
- Очистка данных и обработка пропусков.
- Исследование данных (качество визуализации, наличие идей, гипотез, комментариев).
- Создание новых признаков (Feature engineering).
- Визуализация распределений и корреляций (Matplotlib, Seaborn).
- Отбор признаков.
- Построение модели и оценка её качества с помощью метрики MAPE.
- Оформление кода и документации для воспроизводимости.

### Этапы работы над проектом  
Работа над проектом включала несколько последовательных шагов:  
1. Загрузка и первичный анализ данных  
Изучение структуры DataFrame, проверка на пропуски и их первичная обработка.   
2. Исследовательский анализ данных (EDA).      
Построение распределений ключевых признаков и визуализация взаимосвязей между ними. Анализ структуры данных, выявление закономерностей.  
3. Feature Engineering  
Преобразование строковых данных, извлечение дополнительной информации, генерация новых признаков, кодирование категориальных признаков.
4. Построение матрицы корреляций и отбор признаков.
5. Обучение модели (алгоритм - RandomForestRegressor).
6. Оценка качества модели.



### Результаты:  
- Проведён качественный анализ данных, выполнена очистка и подготовка датасета;  
- Построены необходимые визуализации: распределения рейтингов отелей, матрица корреляций признаков;    
- Сформированы выводы о структуре данных; выявлены ключевые признаки (Top-15 фичей);    
- Обученная модель достигла значения метрики MAPE = 12.84 на публичном лидерборде (базовое решение: MAPE = 14.1).


### Выводы:  
- Установлено, что наибольшее повышение точности модели удалось получить именно за счет генерации новых признаков из имеющихся данных, особенно при поиске ключевых слов в тексте отзывов.
- Отбор признаков на этапе анализа важности признаков для целевой переменной принес вклад не более 0.2 процентных пунктов. При этом удаление большего количества признаков даже ухудшает качество модели.
- Наибольшую ценность в предсказание модели внёс признак "доля позитивных слов", то есть (количество позитивных слов / общее количество слов в отзыве), что отражает позитивную "окраску" отзыва.
