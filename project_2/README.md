### Описание проекта  
Проект посвящён анализу вакансий HeadHunter, хранящихся в базе данных PostgreSQL.
Основная цель — показать, как объединить возможности Python и PostgreSQL для проведения полноценного анализа данных.

Для связи Python и Postgres используется библиотека psycopg2, позволяющая отправлять SQL‑запросы из Python и получать результаты для дальнейшей обработки и визуализации.
### Введение
Перед построением модели необходимо выполнить этап Data Understanding — изучить структуру данных, выявить закономерности, аномалии и особенности рынка труда.

Проект включает несколько этапов анализа:
* знакомство с данными
* предварительный анализ
* детальный анализ вакансий
* анализ работодателей
* предметный анализ

### Какой кейс решает?  
Проект решает задачу анализа вакансий для подготовки данных к ML‑модели рекомендаций.  
Такой анализ помогает:
* понять структуру рынка труда
* выявить востребованные навыки
* оценить активность работодателей
* определить факторы, влияющие на зарплатные предложения
* подготовить данные для дальнейшего моделирования

**Метрика качества**  

Основной «метрикой качества» выступает:
* полнота и корректность SQL‑запросов
* логичность интерпретации результатов
* выявление закономерностей и аномалий 
* качество визуализаций и выводов

**Что практикуем**  

В проекте отрабатываются навыки:
- подключение к PostgreSQL через psycopg2 
- написание SQL‑запросов различной сложности
- объединение Python и SQL для анализа данных  
- исследовательский анализ данных (EDA)  
- визуализация результатов (Matplotlib (pyplot), Seaborn)  
- интерпретация данных и формулирование выводов


### Краткая информация о данных  
Данные хранятся в СУБД PostgreSQL.  
Используемые таблицы включают:  
* vacancies — информация о вакансиях
* employers — данные о работодателях
* areas — регионы
* industries — отрасли
* employers_industries - вспомогательная таблица для организации связи между работодателями и сферами их деятельности 


### Этапы работы над проектом  
Работа над проектом включала несколько последовательных шагов:  
1. Знакомство с данными.     
- изучение структуры таблиц
- первичная проверка качества данных
2. Предварительный анализ данных.      
- подсчёт количества вакансий, работодателей, регионов, сфер деятельности  
3. Детальный анализ вакансий.  
- распределение вакансий по регионам
- анализ зарплатных предложений
- оценка полноты данных
- исследование требований к кандидатам
4. Анализ работодателей.  
- анализ активности работодателей
- крупнейшие работодатели
- активность компаний в разных регионах
5. Предметный анализ.  
- анализ вакансий Data Scientist
- анализ навыков и ключевых слов
- сравнение зарплатных вилок
- выявление факторов, влияющих на предложения

### Результаты:  
В ходе проекта были получены следующие результаты:
1. проведён комплексный анализ структуры базы данных
2. изучено распределение вакансий по регионам и работодателям
3. выявлены ключевые особенности вакансий Data Scientist
4. построены визуализации, отражающие:

* структуру вакансий по регионам
* активность работодателей 
* картину спроса специалистов на должность DS



### Выводы:  
- Использование Python и PostgreSQL позволяет эффективно объединять SQL‑запросы и аналитические инструменты Python.
- Анализ вакансий hh.ru  выявил закономерности, важные для построения рекомендательной модели.    
- Вакансии Data Scientist имеют выраженную структуру требований, зависящую от опыта, навыков и региона.
- Работодатели демонстрируют разную активность в зависимости от отрасли и географии.
- Подготовленные данные могут служить основой для дальнейшего ML‑моделирования.
